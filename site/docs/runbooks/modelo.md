# Runbook: título do procedimento

- **Quando usar:** situação que dispara este procedimento.
- **Quem executa:** perfil responsável.
- **Impacto:** o que muda ou fica indisponível.
- **Tempo estimado:** minutos.

## Pré-requisitos

- Acesso, ferramentas e informações necessárias.

## Passos

1. Primeiro passo, com o comando exato.
2. Segundo passo.

## Como verificar

O que confirma que deu certo.

## Como desfazer

Passos para reverter, se aplicável.

## Contatos e referências

Links para ADRs, dashboards e responsáveis.
